# 反转策略 V2：已披露风险筛选与固定锚点修复退出

这是用户要求精进策略后的研究版本，不连接交易 worker，不下单。原 V1 冻结运行目录保留。V2 会更新 `data/reversal/latest/` 与平台的只读研究卡片。

## 能回答的问题

本版检查：在剔除**当时已经披露且资料覆盖到的**基本面恶化后，短期行业相对反转是否更有用；以及按偏离修复程度退出，是否优于固定持有五日。筛选通过仅表示“未检测到这些风险”，不是证明下跌非理性。

SEC 8-K 通常可以在事件发生后四个工作日内申报，新闻、业绩指引和分析师预期可能更早变化。本版没有完整点时新闻/预期库，因此不能判断每次下跌的真正原因，也不能回测“避开未来即将发布的财报”。参见 [SEC API](https://www.sec.gov/search-filings/edgar-application-programming-interfaces) 和 [Form 8-K](https://www.sec.gov/files/form8-k.pdf)。

## 固定规则

沿用 V1 的月度流动性/历史长度/价格/同行数筛选及原 E01 前10%候选，过滤后不扩展名单。四个固定组全部使用修正后的190只基础样本、$100,000初始资金及相同账本约束：

| 组 | 入场 | 退出 |
|---|---|---|
| B0 | 原 E01 | 原固定5个交易日间隔 |
| X1 | 原 E01 | 整套动态退出 |
| F1 | 新入场过滤 | 原固定5个交易日间隔 |
| V2（预先指定主组） | 新入场过滤 | 整套动态退出 |

新入场过滤：股票过去5日自身收益为负；相对同行的负对数收益偏离至少0.02；可比收入同比至少−5%，净利润为正、同比至少−20%；财报/8-K 2.02可用后的5个交易日内不入场，指定严重8-K风险可用后的20个交易日内不入场。同比净利润用 `(当期−上期)/abs(上期)`，基期为零时未知。任何必要资料缺失、不完整、过时或存在未分类8-K事件时跳过。

风险事件项包括1.03破产、1.05重大网络安全、2.04加速履行义务、2.05退出/处置成本、2.06重大减值、3.01退市/上市要求、4.01审计机构变化、4.02财务报表不可信。某些事项并不必然利空，这是保守事件风险代理。

动态退出：信号日冻结 `entry_gap = log(1+同行5日收益) − log(1+个股5日收益)`。从信号之后第一会话开始，累计每天 `log(1+个股日收益) − log(1+剔除自身后的同行日均收益)`。累计修复达到冻结gap的80%时触发，不能通过滚动窗口令旧跌幅自然过期。持仓每日收盘按以下优先级检查：

1. 已知基本面风险；正常财报冷静期、资料未知本身不会强制卖出。
2. 经拆股/股息权益处理的持仓总回报跌至−5%（不含交易费）。
3. 相对同行累计再下跌一个入场gap。
4. 相对偏离已修复80%。
5. 最长持有10个交易日间隔。

触发后下一交易日开盘代理卖出；缺价或无法交易则保留退出并重试。任一天缺少残差路径时，禁用不完整路径的修复/相对恶化判定，基本面、价格风控和时间兜底仍有效。价格跳空可能造成实际损失超过5%；本版不是盘中触价成交。如果入场开盘时已越过目标，仍在入场当日收盘评估，这是明确保留的日线近似限制。

最多20只持仓、每天新买最多4只、单证券/发行人5%、行业25%、日新增买入20%。只做多、不借款、整股、卖出现金按历史T+3/T+2/T+1结算，现金收益零；不在同日卖出后重买。

## 数据和点时处理

行情沿用封存的Alpaca SIP raw/split/all日线，Robinhood仍只承担原有的抽样核验。新增SEC submissions及其历史分页和companyfacts原始JSON、请求来源和SHA256。财务只使用标准US-GAAP、实体级、USD、同概念同期间长度的收入/利润；季度优先于同一期末年度，否则最近年度备用。季度期末超过200自然日、年度超过460自然日视为过时。当前最新报表无法得到可比数据时不继续假定旧报表健康。

每条事实保留filed与accession；严格在披露日**之后**的下一交易日收盘才允许用于判断。后续修订只从其自身披露时间起可用，不按财报期末回填。此保守延迟能防止同日盘后信息泄露，但SEC今日聚合API仍不是当年每日存档，无法消除后续抽取修订风险。

原身份隔离保留，并在各组统一新增TSM、AZN（ADS/历史ADS）、APC、FOXA（代码复用/身份断裂）。依据和全样本筛查结果见 `data/reversal/v2_identity_review.json`。这不代表全市场历史证券身份已完全认证。当前CIK与前身不同而无映射的历史财务标记未知；不使用当前新公司的资料给旧公司背书。

仍存在当前存续证券预选、当前行业分类回填、退市覆盖不足等限制。原版43.33%来自旧股票池；V2比较对象是修正同池后重新运行的B0。
